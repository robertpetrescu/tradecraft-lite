# TradeCraft Lite — Free Single-File Local Service Website Template

A super-fast (~32KB), zero-dependency, mobile-first HTML landing page template engineered for local trades and home service businesses (Electricians, Plumbers, HVAC, Roofers, Landscapers, Handymen).

- **Live Demo (all 8 trade themes):** https://tradecraft-kit.netlify.app/
- **Zero dependencies:** No npm, no React hydration lag, no WordPress plugins, no broken stock images.
- **Built for local conversions:** Sticky mobile Call + Quote bar, above-the-fold estimate form (`data-netlify="true"` ready), inline SVG icons, FAQ accordion, and `LocalBusiness` JSON-LD SEO schema.

## Quick Start

1. Open `index.html` in your browser to preview locally.
2. Edit the business name, phone number (`tel:` link), city, services, and reviews.
3. Deploy free in 60 seconds via Netlify Drop, Cloudflare Pages, or GitHub Pages.
